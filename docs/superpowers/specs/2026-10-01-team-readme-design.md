# 团队仓库根 README 设计

## 目标

在团队共享仓库根目录新增 `README.md`，让三名成员进入仓库后能快速理解项目目标、分工、目录归属、成员 C 的版本入口，以及后续联调必须统一的接口。

## 内容结构

1. 项目简介：盘古 676 上的 HDMI 视频链路与任意角度图像矫正。
2. 总体数据链：HDMI 输入 -> RGB 像素流 -> 图像处理 -> HDMI 输出。
3. 三人分工：A 负责 FPGA 顶层与工程整合；B 负责图像算法、软件参考和定点化；C 负责视频时序、HDMI 链路与板卡联调。
4. 仓库导航：说明根目录算法版本和 `member_c/VideoTimingSim` 的用途，不猜测未被仓库证实的成员进度。
5. 成员 C 版本：链接 V1、V2、V3 分支，并说明每个版本的核心成果。
6. 联调接口：列出分辨率/帧率、RGB 位宽、pixel clock、HSYNC、VSYNC、DE、坐标方向、定点格式和帧/行边界。
7. Git 协作：成员分支、版本标签、审核后合并，避免直接覆盖其他成员内容。

## 边界

- 不修改 `member_c/VideoTimingSim/README.md`。
- 不改动 A、B 的代码或目录。
- 不把未经验证的 A、B 进度写成已完成。
- 本次只新增根 README，不合并团队 `main`。

## 验收标准

- Markdown 能在 GitHub 正常显示。
- 所有目录与分支链接有效。
- 分工与现阶段约定一致。
- Git 提交仅包含规格说明和随后新增的根 README。
