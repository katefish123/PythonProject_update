# Lens pipeline implementation contract

Scope: calibration JSON → undistorted ideal pixel coordinate → Brown k1/k2/p1/p2 observed source coordinate → existing cache/bilinear stage. Homography precedes lens mapping. The new path takes an explicit destination-to-ideal-source H and does not detect colored/black markers. Existing marker demo remains a legacy entry point.

Calibration profile: image width/height must match the decoded source exactly. Parse the delivered nested `model.K`/scalars/distortion vector and `video.width,height`; validate finite values, zero skew and last row [0,0,1], positive fx/fy, distortion vector length 4 or 5 with k3=0, and agreement between redundant fields. No implicit resizing, cropping, or perspective change of K. Provisional profiles are usable for software experiments and retain their deployment status in reports.

Hardware format: FX_Q16,FY_Q16,CX_Q16,CY_Q16 signed32 / 16 fractional; INV_FX_Q30,INV_FY_Q30 signed32 / 30 fractional; K1_Q26,K2_Q26,P1_Q26,P2_Q26 signed32 / 26 fractional. Quantize constants round to nearest, ties away from zero. Reject a hardware export if not representable, fx/fy<=0, reciprocal rounds to zero, or any distortion coefficient |value|>2. Intrinsics refer to pixel centers. Q26 S=67108864.

Exact integer operations, arithmetic shifts rounding toward minus infinity:

```
x = (((u_q8 << 8) - CX_Q16) * INV_FX_Q30) >> 20
y = (((v_q8 << 8) - CY_Q16) * INV_FY_Q30) >> 20
reject numerical mapping if abs(x)>2*S or abs(y)>2*S
xx=(x*x)>>26; yy=(y*y)>>26; xy=(x*y)>>26; r2=xx+yy
inner=K1_Q26+((K2_Q26*r2)>>26)
radial=S+((r2*inner)>>26)
tx=((P1_Q26*(2*xy))>>26)+((P2_Q26*(r2+2*xx))>>26)
ty=((P1_Q26*(r2+2*yy))>>26)+((P2_Q26*(2*xy))>>26)
xd=((x*radial)>>26)+tx; yd=((y*radial)>>26)+ty
sx_q8=((xd*FX_Q16)+(CX_Q16<<26))>>34
sy_q8=((yd*FY_Q16)+(CY_Q16<<26))>>34
```

If disabled or all four quantized distortion coefficients are zero, pass input Q8 coordinates exactly. Input numerical error always propagates with zero output coordinates. Valid numeric results outside the source frame (including negative coordinates) are not numerical errors; the cache stage returns black, zero addresses/weights and an ordered response. Nearest uses floor((q8+128)/256); bilinear requires 0≤q8≤(size−1)*256, clamps the upper neighbor on the last row/column, and truncates once after the final interpolation accumulator.

RTL leaf `lens_distort_coord` parameters: ENABLE=1,TAG_W=26 plus the ten uppercase profile names above. Ports by name: clk,rst_n,in_valid,in_error,in_x[19:0],in_y[19:0],in_tag[TAG_W-1:0]; out_valid,out_error,out_x signed[39:0],out_y signed[39:0],out_tag. Synchronous pipeline, active-low reset, initiation interval 1, fixed documented latency, same latency for bypass/error/normal, reset flushes all valid bits. No backpressure. Constants are compile-time parameters, exported from JSON; runtime serial transport is not part of this stage.

Implemented latency: ten register stages, input edge E0 to output edge E9 (nine clock intervals). The existing H stage retains its unsigned20 Q8 ideal-coordinate domain 0..4095+255/256 and rejects negative ideal coordinates, ratios >=4096, and denominator <=1/16. The lens stage's signed output and subsequent bounds checks do not expand that earlier H domain.

RTL test vector decimal row: `tag u_q8 v_q8 in_error expected_error expected_sx_q8 expected_sy_q8`. `vectors/lens_coord.txt` is generated by the host from the Python integer model. Testbench must compare every returned tag/coordinate/error exactly, exercise gaps and a mid-pipeline reset, and include zero-distortion/disabled behavior. Root owns generated vectors and compile lists.

Public Python interface: `load_calibration(path, image_size=None)` returns a profile with fx,fy,cx,cy,k1,k2,p1,p2,width,height and deployment metadata; `profile.to_hardware()` returns uppercase integer dictionary above. `map_lens_float(profile,u,v)` returns sx,sy,valid; `map_lens_fixed(profile,u_q8,v_q8,enabled=True)` returns integer sx_q8,sy_q8,valid. `render_lens_float` and `render_lens_fixed` take image/profile, optional destination-to-ideal-source H and output size, method bilinear/nearest; new CLI entry is `python -m brect.lens_cli`.

Acceptance: strict parser failures and size mismatch; zero-distortion identity; float source map against OpenCV's independently implemented model; integer/RTL bit equality; combined H+lens+actual cache-response+bilinear output; invalid/negative/border coordinates; request/tag order, gaps, reset; existing eight RTL regressions. Real 18mm frames get a saved software preview and mapping error statistics. No claim of physical board performance or final optical precision from simulation.
