# 算法和验证规则

## 坐标约定

左上像素中心 `(0,0)`，x 向右、y 向下。四个点依颜色身份固定为 `P0=红, P1=绿, P2=黄, P3=蓝`，对应输出 `(0,0),(W-1,0),(W-1,H-1),(0,H-1)`。输出整数坐标→源小数坐标→读缓存→插值。整页平面的单应模型同时变换 x,y，并含随位置变化的分母。

质心：每帧按颜色累加 `sum_x,sum_y,N`，输出 `(sum+floor(N/2))/N`，整数除法向下取整，恰好半像素向正方向取整。RTL 单个 40 位无符号迭代除法器串行计算八个质心分量；一帧首、尾有效像素均包含在统计中。颜色阈值重叠造成多重命中的有效像素会拒绝整帧，避免双重计数。

## 独立浮点参考

对每个目的角 `(x,y)` 与源角 `(u,v)` 建立：

```text
h00*x+h01*y+h02 - u*h20*x-u*h21*y = u
h10*x+h11*y+h12 - v*h20*x-v*h21*y = v
```

八行构成 8×8 方程组，用 `numpy.linalg.solve` 求八个未知量，令 `h22=1`。这是对硬件闭式参数计算的独立参考，不使用 cv2 的几何变换函数。

## FPGA 内参数求解

先计算单位目的方形 `(u,v)∈[0,1]²` 到源四边形的闭式系数：

```text
dx1=x1-x2; dx2=x3-x2; dx3=x0-x1+x2-x3
dy1=y1-y2; dy2=y3-y2; dy3=y0-y1+y2-y3
det=dx1*dy2-dx2*dy1
g=(dx3*dy2-dx2*dy3)/det
k=(dx1*dy3-dx3*dy1)/det
a=x1-x0+g*x1; b=x3-x0+k*x3; c=x0
d=y1-y0+g*y1; e=y3-y0+k*y3; f=y0
```

代入 `u=x/(W-1),v=y/(H-1)`，得到像素目的坐标对应的 H：

```text
[ a/(W-1)  b/(H-1)  c ]
[ d/(W-1)  e/(H-1)  f ]
[ g/(W-1)  k/(H-1)  1 ]
```

定点 `S=2^24`：`gq=trunc(ng*S/det)`、`kq=trunc(nk*S/det)`，后续 a/b/d/e 的分子均是“整数差×S + gq/kq×角点”。矩阵系数共享同一个 64 位有符号迭代除法器，共八次除法，每次约64个时钟加控制拍。所有中间量范围由12位角点、det≥16以及配置尺寸限定，结果缩窄前检查40位范围。

这个 solver 每次成功生成整套 H 后才更新输出；错误保持前一套 H。wrapper 把它放到 pending 寄存器，目的帧开始时整体切到 active。若新结果与旧 pending 的提交同拍，旧 pending 生效，新结果仍等待下一帧。

## 每像素映射

```text
Nx=h00q*x+h01q*y+h02q
Ny=h10q*x+h11q*y+h12q
D =h20q*x+h21q*y+h22q
sxq=floor(Nx*256/D)
syq=floor(Ny*256/D)
```

先拒绝 `D<=S/16`、负分子、超48位、以及比例≥4096的输入。正常结果是 UQ12.8。映射错误置 `out_error` 并输出零坐标；正常数学结果但超过源图像边界只让 `req_inside=0`，不当成算术错误。

`scaled_div_pipe` 不用组合变分母除法。前12级逐位求整数部分：比较/减去 `D << bit_index`；后8级每拍余数乘2，比较/减D，求小数部分。各级有自己的分母、余数、商、有效位和标签，因此可连续接收每拍一个不同分母的请求。

`perspective_coord` 的寄存边沿：E0 乘加，E1 除法输入级，E2..E21 二十个求商级，E22 核心输出。输入到输出22个时钟间隔，共23个寄存级；空拍和复位在同一有效流水线上传播。

## 采样规则

最近邻：`ix=(sxq+128)>>8`，iy同理，恰好半像素向正方向取整。以取整后的坐标判断缓存边界，所有四地址都设成同一个地址，fx/fy=0，因此复用插值器做直通。

双线性：先检查 `0<=sxq<=(SRC_W-1)*256` 和y边界，再拆 x0/y0、fx/fy。x1/y1在右/下边界钳位，不越行、不读帧外。

```text
top=p00*(256-fx)+p10*fx
bot=p01*(256-fx)+p11*fx
rgb=(top*(256-fy)+bot*fy)>>16
```

三通道各自计算，最后截断，与 v3 的全精度中间插值规则一致。本版并未用较低精度的逐行舍入来节约位宽。

## 误差和验证

参数小数位为24，源坐标小数位为8。正坐标截断本身引入 `<1/256` 像素误差，此外有H量化误差。越接近小分母、尺寸越大，误差越大；有效包络之外直接拒绝更新。

`scripts/test_models.py` 用独立8×8解与闭式定点解交叉检查：80个随机四边形、角点/内部坐标，以及1920×1080源、1280×720目的的采样网格。HD测试要求坐标误差<0.25像素，不意味着所有合法透视都达到同一误差。

小场景浮点/定点坐标最大误差约0.00395像素，双线性图三通道平均误差约0.092、最大1灰阶；第二个最近邻场景恰好逐像素一致。高频纹理和恰好靠近最近邻舍入边界的坐标可以产生更大的像素差异。实际结果记在 `vectors/manifest.json`，不要把少数场景的误差当成全场景保证。

五个 testbench 都通过以后，验证脚本还重新读取实际 RTL 导出的 CSV，与 Python 独立重算结果逐笔比对，并从 RTL 像素重建 PNG。覆盖连续请求、空拍、分母阈值、系数正负、比例溢出、颜色边界、末像素、busy时丢弃快照、缺色、散点、坐标越界、更新前黑屏、pending等待、首像素换H、失检保持、复位中断。
