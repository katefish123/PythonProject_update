## 3. 单口 RAM single_port_ram

- 设计文件：`Projects/single_port_ram_demo/rtl/single_port_ram.v`。
- 仿真文件：`Projects/single_port_ram_demo/sim/tb_single_port_ram.v`；仿真顶层：`tb_single_port_ram`。
- 容量：16×8 bit=16 字节。addr 是读写共用地址，范围 0～15。
- 时钟/复位：上升沿操作；无复位、无存储初始化。
- 写入：上升沿 we=1 时，mem[addr] 写入 din；dout 保持。
- 读取：上升沿 we=0 时，dout 更新为 mem[addr]。地址改变不会立即改变输出；没有独立读使能。
- 初始行为：未写入的存储位置与尚未有效读取的 dout 可为 X，属于预期。
- 测试：全地址写入 A0～AF并读回；覆盖地址 3/0/15 为 55/00/FF；再次读遍全地址；检查写入期间输出保持、上升沿之前输出保持。
- 结果：截图显示 516 ns 结束，errors=0，最终 dout=FF；在上述覆盖范围内 RTL 功能仿真符合预期。
- 已核实结果截图：`TEST PASS: all single-port RAM checks passed.`，结束时间 516 ns。
- 结果证据：[单口 RAM 控制台结果](images/single_port_ram_result.png)。

## 4. 简单双口 RAM dual_port_ram

- 设计文件：`Projects/dual_port_ram_demo/rtl/dual_port_ram.v`。
- 仿真文件：`Projects/dual_port_ram_demo/sim/tb_dual_port_ram.v`；仿真顶层：`tb_dual_port_ram`。
- 容量：16×8 bit=16 字节。一端口专写、一端口专读，地址独立；不是两个端口均可读写的真双口 RAM。
- 时钟/复位：两个端口共用 clk，上升沿操作；无复位、无存储初始化。本次不涉及双时钟或跨时钟域。
- 写入：we=1 时，在上升沿将 din 写入 mem[wr_addr]。
- 读取：re=1 时，在上升沿将 mem[rd_addr] 送至 dout；re=0 时 dout 保持。
- 并行规则：we=1 且 re=1 时，可在同一上升沿写一个地址并读另一个地址。
- 测试：写入 A0～AF并全读回；同时向地址 i 写入 50+i、从地址 (i+1)%16 读取；再次全读回 50～5F；re=0 时向地址 3 写 CC并改变读地址，验证输出保持；恢复读取地址 3得到 CC。
- 结果：截图显示 686 ns 结束，errors=0，最终 dout=CC；在上述覆盖范围内 RTL 功能仿真符合预期。
- 已核实结果截图：`TEST PASS: all dual-port RAM checks passed.`，结束时间 686 ns。
- 结果证据：[双口 RAM 控制台结果](images/dual_port_ram_result.png)。
- 波形证据：[双口 RAM 波形](images/dual_port_ram_wave.png)。
- 未覆盖：同地址同时读写、双时钟。当前 RTL 的同地址同时读写仿真会读到旧值，但实际存储资源的冲突模式需结合 PDS 综合结果或 IP 配置确认，不能直接推定硬件行为。

## 5. 单时钟 FIFO sync_fifo（2026-10-04 新增）

- RTL：`C:/D/FPGA/demo/Projects/sync_fifo_demo/rtl/sync_fifo.v`。
- 基础 TB：`C:/D/FPGA/demo/Projects/sync_fifo_demo/sim/basic/tb_fifo_basic.v`。
- 边界 TB：`C:/D/FPGA/demo/Projects/sync_fifo_demo/sim/boundary/tb_sync_fifo.v`。
- 容量：8 位 × 16 项；4 位读写指针，5 位 count，数量范围 0～16。
- 复位：rst_n 低有效异步复位；指针、count、dout 清零，不复位存储阵列。
- 有效写：wr_en && !full；有效读：rd_en && !empty；依据上升沿之前的空满状态判断。
- 同步读取：有效读在上升沿之后更新 dout，无有效读保持。
- 空时同时读写只写，满时同时读写只读，中间状态同时读写数量不变。
- 基础截图：结束时间 146 ns，errors=0；写入/读出 11、22、33、44（十六进制），数量 0→4→0。
- 边界截图：前约 580 ns 定向测试可见空读、满写、连续读写及同时读写；errors=0。
- 本次聊天另有完整运行截图：结束时间 11266 ns、errors=0、checks=0x464=1124，最终 dout=expected_dout=D7、count=0。该总览未作为本次要求的两张图归档。
- TB 覆盖：空读、空时同时读写、写满、满写、满时同时读写、连续读取、中间状态同时读写、指针绕回、带数据复位、1000 次随机操作及最终排空。
