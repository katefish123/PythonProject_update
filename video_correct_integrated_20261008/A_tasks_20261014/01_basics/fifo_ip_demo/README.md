# 现成 FIFO IP 最小实验验收记录

验收日期：2026-10-06。用途：学习 PDS 配置现成 FIFO、连接模块和 ModelSim 功能仿真。

本次完成了 8 位 × 512 项单时钟 FIFO 的配置、连接、基础与边界功能仿真，以及 Pango ADS 综合。没有完成真实板卡引脚、目标频率时序和上板验收。正式 video_correct_fpga 工程未因本实验而修改。

## 工程与配置

- 工程：fifo_ip_demo.pds；设计顶层：rtl/fifo_ip_top.v。
- 工具：PDS 2022.2-SP6.4、Pango ADS、ModelSim SE-64 2020.4。
- 器件：Logos2、PG2L100H、-6、FBG676；目标板卡完整料号 PG2L100H-6IFBG676、MES2L676-100HP。
- IP：Pango DRM Based FIFO 1.10，ipcore/fifo_sync_8x512/fifo_sync_8x512.idf。
- 类型：SYN_FIFO；读写位宽 8；读写地址位宽 9；容量 512 项，合计 512 字节。
- DRM AUTO，当前使用 DRM18K；低功耗、Byte Write、两级可选输出寄存、rd_oce、输出时钟反向均未启用。
- 两侧水位输出均启用，位宽为 [9:0]；将满阈值 508、将空阈值 4。
- IP rst 高有效、ASYNC 复位，输出复位值 0；学习顶层 rst_n 低有效，通过取反连接 IP。

## 连接与使用规则

所有顶层请求属于同一 clk 时钟域。write_accept = wr_en && !full && rst_n；read_accept = rd_en && !empty && rst_n。外部请求经保护逻辑后才进入 IP。

- 非满可写，非空可读；每次接受操作发生在时钟上升沿。
- 非满且非空时同时读写：读出旧队头，写入新队尾，数量不变。
- 空时同时读写：只写；满时同时读写：只读。判断依据为上升沿之前的标志。
- almost_full 在水位达到 508 时置位，下降到 507 时清除；almost_empty 在水位不超过 4 时置位。
- 本配置的有效读取结果在接受读请求的上升沿后更新；TB 延后 1 ns 采样。没有单独的数据有效输出，不应将保留的 dout 当作新数据。
- 读出行为为读使能触发的同步读取：有数据但未提出有效读取请求时，不自动把队头作为新结果输出。没有启用额外输出寄存级；读取发生在接受 read_accept 的上升沿，结果在该沿后更新。TB 的 #1 仅是避开更新竞争的采样等待，不是硬件读取延迟为 1 ns 的声明。
- 水位数量与地址位宽不同：9 位地址表示位置 0～511；10 位水位表示数量 0～512。
- 单时钟 FIFO 不承担跨时钟域传输。视频工程中的时钟域、复位释放与容量需另行确定。

```tcl

```

基础检查：复位、连续写入 11/22/33/44（十六进制）、暂停和顺序读取、水位与空满标志。结果 PASS: Pango FIFO IP basic, 0 errors，176 ns 结束。用户截图与助手独立运行结果一致。

边界检查入口：


脚本先停在 5300 ns，显示写满附近。5175 ns 水位到 512，5185 ns 满写被拒绝，5195 ns 满时同时读写只接受读取。

完整检查覆盖：空读、空时同时读写、写满 512 项、拒绝满写、满时同时读写、完整排空核对数据、非空非满同时读写、跨越多轮存储位置、带数据复位与恢复、1000 次随机读写、最终排空和将满/将空阈值。使用独立线性参考队列核对结果。

结果 PASS: Pango FIFO IP boundary, 3169 checks, 0 errors，31716 ns 结束。用户截图与助手独立运行结果一致。

仿真使用生成的真实 IP 和本机 PDS 官方 GTP_GRS、GTP_DRM18K_E1 模型，没有用学习版 sync_fifo 替代。日志：sim/modelsim_basic_check.log、sim/modelsim_boundary_check.log。

用户完成新版 Compile 与 Synthesize；截图与 synthesize/run.log 均确认完成，日志中 fabric_ads 确认使用 Pango ADS。综合报告显示 GTP_DRM18K_E1 为 1 use，顶层实际引用 fifo_sync_8x512。

旧 64 项版本曾完成布局布线与 bitstream 生成；其结果不作为当前 512 项版本的实现验收。512 项版本当前验收至综合。不得把旧 bitstream 用作新版验证依据。

## 64 项版本保留说明

IP 配置界面和随工具提供的手册允许地址位宽 6，但生成的内部 sdpram 模块在 ModelSim 中对 DRM18K 给出地址位宽须为 9～20 的参数检查提示。本实验改为 9 位、512 项后，该提示消失。未修改厂商生成代码的参数检查。

旧 fifo_sync_8x64 保留为配置比较记录，目前也仍在 PDS 的 IP 文件列表中；当前 fifo_ip_top 不调用它，综合有效设计为新版。切换前的连接和基础测试文件保存在 backup/before_8x512。

## 与 FIFO 最小实验任务清单逐项核对

1. Pango FIFO IP 及参数记录：完成，8 位、512 项、单时钟、读使能触发的同步读取，延迟与数据有效规则见上文。
2. ModelSim 写入一串数字再顺序读出：完成，基础 TB 为 11/22/33/44，边界 TB 使用独立参考队列逐项比较并排空。
3. 满空、写使能、读使能、输出关系：完成，用户核对基础及满边界波形，测试同时核对数量、空满和阈值标志。
4. 连续、间歇、写满、读空、复位：完成。定向测试覆盖连续读写与边界、基础测试覆盖暂停，1000 次随机操作覆盖间歇请求；没有额外单独命名的固定间歇序列测试。
5. 外围满写、空读保护：完成，rtl/fifo_ip_top.v 的 write_accept/read_accept 实现保护，边界测试核对被拒绝操作不会改变队列。
6. 异步 FIFO 不同频率时钟验证：尚未执行，属于后续确认需要跨域后再做的条件项。当前实验全部属于单时钟域。

完成标志针对已执行的测试范围和当前配置。正常运行时的被接受写入逐项按顺序读回；有意复位会清空队列，复位前未读数据不要求复位后保留。满空边界结论针对本次外围保护加 IP 的组合，不推断厂商 IP 在非法裸读写下也会自动保护。

成果已具备：IP 配置与生成代码、使用 IP 的顶层、两份 TB、运行脚本、文本日志和关键截图。归档图片：docs/images/ip_basic_wave.png、docs/images/ip_full_boundary_wave.png、docs/images/ip_boundary_pass.png，均来自用户实际操作截图。
