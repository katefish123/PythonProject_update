## 基础组件

### A01 PLL 生成系统时钟

原清单项目：PLL 锁相环 / 生成需要的时钟。

PLL 像时钟变速器。板上27MHz不能直接承担1080p像素扫描，已有IP分别产生显示时钟和配置时钟。locked表示输出时钟已经稳定；A要让相关模块在时钟稳定后再解除复位。

复用方式：直接复用 Pango IP，与 C 核对配置。

代码入口：[video_pll_27m_148m5.v](<C:/D/FPGA/video_correct_integrated_20261008/A_tasks_20261014/03_partner_reference/C_and_vendor/video_pll_27m_148m5.v:18>)、[config_pll_27m_10m.v](<C:/D/FPGA/video_correct_integrated_20261008/A_tasks_20261014/03_partner_reference/C_and_vendor/config_pll_27m_10m.v:18>)、[video_correct_ddr_top.v](<C:/D/FPGA/video_correct_integrated_20261008/A_tasks_20261014/02_system/video_correct_ddr_top.v:4>)。

工程已有：旧黑标顶层已连接27MHz到148.5MHz视频PLL、27MHz到10MHz配置PLL；DDR使用自己的参考和生成时钟。

后续要补：和C核对实际相机输入模式、IP配置和时钟约束，不能只看PLL模块名就认定整个链路频率正确。

A应交付：一张时钟表，记录模块、频率、时钟来源、locked及复位条件。

理解自检：能指出顶层的vp、cp两个实例，并解释为什么不能用sys_clk_27m直接驱动显示扫描。

### A02 FIFO 暂存与排队

原清单项目：FIFO 先进先出队列 / 暂存流过来的数据。

FIFO按先写先读的顺序存数据。full表示不能再接收，empty表示没有可读数据；dout保持旧值时不代表有新数据。单时钟FIFO用于一个时钟域，视频接收和DDR时钟不同则要用异步FIFO。

复用方式：厂商 IP 或已经验证的 FIFO RTL。

代码入口：[sync_fifo.v](<C:/D/FPGA/video_correct_integrated_20261008/A_tasks_20261014/01_basics/sync_fifo_demo/rtl/sync_fifo.v:3>)、[fifo_ip_top.v](<C:/D/FPGA/video_correct_integrated_20261008/A_tasks_20261014/01_basics/fifo_ip_demo/rtl/fifo_ip_top.v:3>)、[async_packet_fifo.v](<C:/D/FPGA/video_correct_integrated_20261008/A_tasks_20261014/02_system/async_packet_fifo.v:5>)。

工程已有：已有8位16项学习FIFO、8位512项Pango FIFO IP实验及日志；实际视频使用285位异步包FIFO，旧黑标顶层把地址位宽设为10，即1024项。

后续要补：学习FIFO的空满规则不能直接套到任何IP。实际视频不能随意暂停，FIFO满时必须标记坏帧，不能把缺像素的一帧继续发布。

A应交付：FIFO参数、复位、读取延迟、数据有效规则和溢出策略说明。

理解自检：能解释空时同时读写为何只写、满时同时读写为何只读，并区分读请求和读数据有效。

### A03 RAM 与简单双口 RAM

原清单项目：RAM 与双口 RAM / FPGA 内的小存储。

RAM通过地址选择数据，适合保存小图或一行像素。简单双口RAM可以一端写、一端读，但不等于两端都能任意读写，也不自动解决跨时钟域问题。读取通常要等时钟沿，坐标和valid必须一起对齐。

A应交付：写读地址、使能、输出延迟及冲突规则说明；能用小图展示addr=y*width+x。

DDR控制器负责板上内存的电气时序、初始化和低层读写。它不会决定哪一帧可以读，也不会自动组织四个邻居像素。A要理解控制器暴露的命令、数据和响应接口，再用自己的缓存封装连接算法。
