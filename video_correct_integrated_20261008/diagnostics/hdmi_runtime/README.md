# 相机 HDMI 接收诊断

独立输出的彩条只承载硬件状态，不代表相机直通或校正成功。控制逻辑取自当前经过启动测试的 HDMI 配置；新增寄存器只观察事务，不修改原 A/B/C 代码或正式工程控制逻辑。

底部 192 行是 16×16 状态格，格子宽 120、高 12，从左到右、从上到下读取。绿色为 1，红色为 0。256 位大端状态：

| 位 | 含义 |
|---|---|
|255:240|固定签名 D103|
|239:224|flags，依次：致命配置错误、启动重试、TX初始化、RX初始化、原始NACK历史、TX scratch验证、RX scratch验证、当前TX所有者、收到RX时钟、见过DE、见过VS、见过HS、cfgPLL锁定、pixelPLL锁定、cfg快照已返回、RX快照已返回|
|223:192|RX 209F/209E/209D/209C 最近读取值，按此顺序拼接|
|191:184|RX 1281 最近读取值|
|183:176|最近完成事务的设备地址字节|
|175:160|最近完成事务的寄存器地址|
|159:152|最近完成事务的读取数据|
|151:144|最近NACK设备地址字节|
|143:128|最近NACK寄存器地址|
|127:112|NACK计数，饱和65535|
|111:96|完成事务计数，饱和65535|
|95:80|最近完整DE行宽|
|79:64|最近VS之间的DE完整行数；没有VS时为0|
|63:48|相邻HS上升沿之间的RX像素时钟周期数|
|47:32|VS上升沿计数，饱和65535|
|31:8|最近DE期间RGB像素|
|7:0|低5位为I2C busy、最近完成事务ownerTX、方向write、最近NACK ownerTX、最近NACK write；高3位为0|

各输入域在请求后保持整个状态包，输出域收到同步确认才读取，输出状态在整帧中保持不变。RX时钟不运行时RX快照不会返回，接收侧数据仍为复位值；要结合flags中的时钟与返回标志解释。频率寄存器是分别读取的最近值，不声称同时读取四个I2C寄存器。帧宽高是接收信号的测量，输出彩条固定1080p60。
