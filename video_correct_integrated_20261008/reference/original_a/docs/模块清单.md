# 图像畸变矫正项目模块清单 v1

## 开发基准

- 正式项目：`C:\D\FPGA\video_correct_fpga`
- 基础练习：`C:\D\FPGA\demo`
- 开发板：MES2L676-100HP
- FPGA：紫光同创 Logos-2 PG2L100H-6IFBG676
- 开发环境：PDS；综合引擎：Pango ADS（Synplify 无授权）
- 计划视频源：佳能 EOS R50，HDMI 输入
- A：FPGA 主程、缓存与工程整合；B：图像算法；C：视频与硬件
