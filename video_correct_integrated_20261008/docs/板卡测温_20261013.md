# 板卡测温

用户报告中央及附近黑色芯片烫，已主动关电。当前真实温度没有测到。10月9日54.4°C为历史片上ADC读数，不能代表这次温度，更不是DDR表面温度。当前提速副本仅在电脑仿真/编译，尚未上板。

PDS官方Fabric Debugger手册第5.7节明确PG2L100H支持ADC Console监测芯片温度与电压。采用现有软件查看即可，先不需要购买测温工具，也不需要下载其他温度示例工程。

板子经过充分断电冷却后，进行一次短时测温：

1. 保持USB/JTAG连接，给开发板上电。
2. 双击工程目录的“打开FPGA测温工具.cmd”。
3. 在Fabric Debugger中连接JTAG服务器。当前使用的服务器为127.0.0.1，端口65420。点击Search JTAG Chain扫描器件，找到PG2L100H。
4. 展开PG2L100H节点，双击ADC Console。显示Temperature通道的当前值和最大值，观察数据时间是否持续更新。
5. 等约15秒，把Temperature当前值和最大值告诉助手。若没有ADC Console或数据没有更新，也如实报告；此前残留的历史图不能作为当前读数。

这一步只读取当前温度，还不下载新校正程序；之后再判断是否进行短时负载测试以及散热措施。FPGA片上温度不能代替两个DDR芯片的表面测温，不据此声称整块板已通过长期散热验收。

参考资料：[PDS官方Fabric Debugger手册](C:/pango/PDS_2022.2-SP6.4/doc/Fabric_Debugger_User_Guide.pdf)，软件说明页45及TCL命令页100。PG2L100H状态寄存器温度结果在40h，最大值在65h，最小值在6Ah；寄存器控制/转换需按该型号定义，不能套用其他系列的格式或默认阈值。

官方Logos2配置指南UG040005表3-14把STATUSR bit27标为over_temp、bit29标为prcfg_over。旧记录中的bit27=1不提供当前实际温度；这里没有确认其有效极性、ADC阈值或当时ADC配置，保留原始状态而不推断正常/过热。
