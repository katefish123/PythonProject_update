# R50相机与OBS联调设置（2026-10-11）

这是本工程用于对照测试的一套设置，不是对相机所有拍摄菜单的要求。当前现场对照：经过b918全像素FPGA预览持续闪烁；相机直接接采集卡，在相同NV12、1920×1080、30fps设置下，用户观察20秒后报告取景稳定、不闪烁。它说明相机当前能够提供可用画面，不能凭此确认每一页菜单或长时间运行均已核验。

## 相机核对清单

|项目|本次联调用的设置|
|---|---|
|拍摄模式|短片模式，进入实时取景|
|设置 → 视频制式|用于NTSC|
|拍摄 → 高帧频|关闭|
|拍摄 → 短片记录尺寸|全高清FHD，1920×1080，59.94帧/秒|
|设置 → HDMI分辨率|1080p|
|拍摄6 → HDMI显示|相机＋外接监视器（相机图标＋监视器图标）|
|设置 → 节电 → 自动关闭电源|关闭|
|拍摄6 → 待机：低分辨率|关；这是本次清晰度对照的设置，不把它直接当作掉线根因|
|拍摄 → HDR拍摄（HDR PQ）|关闭；本工程先使用普通画面作对照|
|实际取景|镜头盖取下，将焦点对准桌面文字或真实物体，退出菜单；用INFO切换辅助显示，尽量保持干净画面|

前四项的帧率与制式依据[佳能R50短片记录尺寸](https://cam.start.canon/zh/C011/manual/html/UG-05_Shooting-2_0040.html)及[高帧频说明](https://cam.start.canon/zh/C011/manual/html/UG-05_Shooting-2_0050.html)。固定1080p依据[佳能HDMI分辨率](https://cam.start.canon/zh/C011/manual/html/UG-09_Set-up_0210.html)。HDMI显示、长时间输出、待机低分辨率和INFO说明见[其他菜单功能](https://cam.start.canon/zh/C011/manual/html/UG-05_Shooting-2_0160.html)。HDR选项见[HDR拍摄](https://cam.start.canon/zh/C011/manual/html/UG-05_Shooting-1_0100.html)。选择关闭高帧频、待机低分辨率及HDR是本工程的对照方案，不能将其说成已验证的闪烁根因。

HDMI显示设为相机＋外接监视器时，官方说明指出不会执行相机存储卡记录；本项目只需实时HDMI取景，不要求按下录像键。若接着HDMI时菜单只出现在电脑画面上，可在OBS中查看并操作相机菜单。

## 当前OBS对照配置

采集源为VC-002Pro，1920×1080、30fps、NV12，缓冲禁用，硬件解码禁用。日志01:07:15已确认生效。相机59.94fps与OBS采集30fps属于不同阶段，本轮直连已证明这一组合可出稳定取景，不能把数字不同本身视为故障。

暂时保持相机直接接采集卡的稳定画面，核对以上设置并记录不一致的选项；若发生调整，应重新观察直连20秒并保存源截图，避免把设置变更前的稳定结论继承到新的格式。经过FPGA才出现持续闪烁，后续重点核对板端接收/发送同步、实际输出时钟、外部IO时序和HDMI-OUT连接。
