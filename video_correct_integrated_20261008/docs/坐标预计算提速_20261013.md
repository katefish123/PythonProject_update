# 坐标预计算提速

当前已上板并实际验证的可用版本仍为eb06c8f9，实测可见校正结果更新约0.85次/秒。新工作在diagnostics/ddr_camera_coordqueue_20261013独立进行，没有改动原A/B/C或当前可用版本，没有下载新版本。

完整960×540源图、640×904结果的逐像素仿真统计：旧frame_processor每个像素都串行等待坐标请求，再读取四邻点、插值和写出。坐标等待阶段13,306,880周期，占总25,094,025周期的约53%。旧阶段统计和每个RGB像素均通过独立既有金标准核对。

新副本仅改变frame_processor的调度。16个预先预留的额度覆盖B坐标管线中的请求、返回后的坐标队列和正在取样的像素；实际源读取、插值输出和公共内存请求依旧一次一条。坐标管线在当前像素取样期间提前计算后续坐标，已返回的地址、比例和标签按顺序保存。只有写回接口真实接收像素才归还额度；复位、异常或超时清空队列，完整帧写入DDR后才允许发布的外部行为不变。

新副本完整十五项检查通过，包括全尺寸578560个RGB精确一致、源采集、显示读取压力、实际三客户仲裁、真实word-engine和核心的响应归属、坐标额度/入队出队守恒，以及复位/超时/写端等待。定向用例验证双线性和最近邻完整帧、越界黑像素且不读越界源、读请求地址和写像素在等待期间稳定，队列最大15、总额度最大16，等待响应超时后清空并可复位恢复。最终芯片时序和发布资格仍需构建结果确认，实际速度等待物理验证。
