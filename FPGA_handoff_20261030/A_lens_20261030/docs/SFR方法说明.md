# 斜边 SFR / MTF50 离线工具

工具为工程估计器，没有 ISO 认证或完整标准符合性声明。输入必须是一条清晰、近似直线的独立斜边。使用者明确选择 PNG、ROI、边缘方向以及亮度传递方式。工具不会寻找棋盘，也不会将棋盘交点当作斜边靶。

## 使用

依赖 Python、NumPy 与 OpenCV。现有离线环境已有这些依赖，不需要访问相机、板卡或网络。

```powershell
python tools/slanted_edge_sfr.py image.png --roi 100 200 160 240 --orientation vertical --transfer srgb --output sfr_result.json
```

ROI 为 `x y width height`，以 PNG 左上角为原点，必须完整位于图内；不会自动截断。`vertical` 表示边缘近似竖直、沿水平方向跨边；`horizontal` 表示边缘近似水平。边缘应偏离相应轴 2°～12°，支持正负倾斜以及明暗反向。ROI 两维至少 64 像素，边缘至边界至少留 24 像素。

`--transfer` 没有默认值：

- `linear`：PNG 数值已代表线性光强。
- `srgb`：逐通道解码，码值不超过 0.04045 时除以 12.92，否则使用 `((C+0.055)/1.055)^2.4`。然后按 BGR 权重 0.0722、0.7152、0.2126 形成线性亮度。传递函数参考 [W3C sRGB 转换示例](https://www.w3.org/TR/css-color-4/#color-conversion-code)。

只支持 8/16 位灰度、RGB 或完全不透明 RGBA PNG。颜色假定为 sRGB/Rec.709 原色；不另行应用 PNG 的 ICC、gAMA 元数据。相机若采用自定义曲线、Log、未知伽马或已经非线性锐化，使用者必须先处理并明确传递方式，不能靠此开关恢复未知光强。

成功输出 JSON 含 `accepted: true`、MTF50、频率/SFR 数组、ESF、LSF、窗后 LSF、补偿曲线、拟合质量以及 PNG SHA-256。拒绝时输出 `accepted: false`、错误代码和原因，不输出伪造的 MTF50，进程退出码为 2。API 为 `analyze_png(path, roi, orientation=..., transfer=...)`，拒绝抛出 `SfrError`。

## 计算方法

逐行梯度定位后拟合直线，按到该直线的**法向距离**以 0.25 像素间距分箱平均，形成四倍过采样 ESF。ESF 用中心差分变为 LSF，乘以以边缘为中心的 Hamming 窗，再作 FFT、按 DC 归一化。中心差分频率补偿为 `2πδf / sin(2πδf)`，其中 `δ=0.25 pixel`，DC 取极限 1。这条基本处理链和差分补偿依据 [Burns 等，2022 年原论文](https://doi.org/10.2352/EI.2022.34.9.IQSP-357)。

采用法向距离投影，距离单位已经包含倾角几何关系；不再重复乘倾角修正。频率仅报告 0～0.5 cycles/pixel，并线性插值求唯一的 50% 下降交点。单位是**当前 PNG 沿边缘法向的像素**，并非物方线对/毫米，也不是传感器原始像元单位。

工程实现固定使用直线拟合、4 倍分箱和 Hamming 窗，不实现标准中的所有目标、拟合阶数、光学条件或非均匀性修正。分箱的有限宽度、窗、量化、噪声及边缘定位会引入误差；中心差分补偿只补偿该差分滤波器，不声称恢复这些其他损失。对相机非线性处理后的结果，SFR 是更审慎的名称，MTF50 在此仅指该归一响应的 50% 位置。

## 保守质量门槛

以下是本工具的工程拒绝条件，不是 ISO 合格线：

- 线性明暗差小于 0.10，或超过 5% 的行存在方向不一致、额外边缘或过多反向梯度。
- 码值端点裁切占比超过 0.5%，或透明像素参与 ROI。
- 直线拟合 RMS 超过 0.25 像素、最大残差超过 0.75 像素。
- 两侧平台噪声/明暗差超过 2%；此项也会拒绝明显阴影、纹理。
- 任一过采样分箱少于 8 个样本，或最大/最小样本数比超过 8；不靠插值填空箱。
- ESF 负向 LSF 能量超过 10%，或归一响应峰值超过 1.25。
- 0～0.5 cycles/pixel 范围没有唯一 50% 下降交点。

空白、条纹、多边缘、棋盘交点、边缘弯曲、ROI 不含边缘、方向错误等应换取样区域；拒绝不能解释为镜头一定不合格。高于 Nyquist 才下降到 50% 的边缘会被拒绝，不把 0.5 当作其测量值。

## 自测及证据

运行 `python tools/check_sfr.py`，结果写到 `verification/sfr_check_<时间>/`。该目录保留两份脚本快照、输入清单、合成 PNG、检查日志和 `verification.json`，每项输入、源码、检查器和日志有 SHA-256。

自测图由连续高斯模糊理想阶跃的解析误差函数产生，在像素中心采样，不包含像素孔径积分。其解析响应为 `exp(-2π²σ²f²)`，所以 `MTF50=sqrt(log(2))/(sqrt(2)πσ)`。测试覆盖 σ=0.7、1.2、2、3 像素、水平/竖直边缘、正负倾角及极性，以及 sRGB 彩色编码；允许相对误差 1.2%。另验证命令行契约和各类明确拒绝。**这些是合成数值测试，不是相机、镜头或板卡实测，也不证明真实系统的 MTF50。**

实际验收需要合适斜边靶、稳定照明、清晰对焦和记录完整的拍摄/处理条件。原图与校正图比较时必须注明裁切、缩放、插值和局部几何尺度：相同 cycles/pixel 数值在不同缩放下不能直接解释为同一物方清晰度。此工具不替代镜头标定、畸变直线度测量，也不输出未经测量的 MTF50 改善结论。
