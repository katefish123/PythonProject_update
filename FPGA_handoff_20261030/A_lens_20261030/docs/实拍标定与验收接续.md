# 相机配合阶段的接续步骤

本文件是后续操作说明，现在不要求开启相机。离线状态和物理实现是否通过，以工程根目录的 `CURRENT_STATE.json` 及最终发布记录为准。不要把仿真30帧、合成图标定或OBS录制帧率当成真实板卡验收。

## 固定相机条件并采集

保持同一镜头、焦距、焦点、HDMI原生尺寸和相机内部处理设置。当前试参数对应R50、18mm、1920×1080。后续应确认并记录是否锁焦，以及机内镜头处理和防抖的实际状态；无法确认的项目保留“未知”，不能用软件默认为已锁定。

将平整棋盘固定在硬底板上，分别测量横向、纵向多格总长度，确认方格没有被打印拉伸。脚本默认9×6内角点，格边长必须填写本次实测值。拍摄不同位置、距离和倾斜姿态，让角点覆盖中心及四周，避开反光、明显运动模糊和相机菜单遮挡。

保存原生1920×1080图片，不先缩放、裁剪、旋转或拉正。训练集至少20张，独立留出集至少8张。两组不能共享同一图片，也不能靠复制图片凑数量。建议留出集在另一次独立采集中获得；软件会检查完全重复的图像，但不能自动证明物理条件独立。

## 本机计算与新工程绑定

1. 填写 `calibration/camera_settings_template.json` 的副本，保留实际设置及数据来源。
2. 使用 `tools/camera_calibration.py`，显式提供 `--train`、`--validation`、`--settings`、`--square-mm` 和一个全新的 `--output` 目录。工具不会覆盖旧标定，读入时不作隐式尺寸转换；支持中文路径。
3. 检查训练重投影残差、留出集姿态拟合残差、角点覆盖及原始/去畸变角点的直线度。留出集姿态拟合不等于重新拟合内参，也不等于已知真值光学测试。新参数始终先标为 `deploy_to_fpga=false`。
4. 使用 `tools/export_lens_profile.py --calibration 新标定JSON --output 全新的候选目录`。该工具同时更新实际镜头常数、默认防黑视野、处理器和跨时钟邮箱的默认矩阵，并保留标定来源。活动候选和旧版源码保持原样。
5. 对新候选重新做数值/完整视频回归、综合布局布线和原生时序审查。导出成功本身不代表新工程已经合格；不能把旧标定对应的下载文件与新上位机参数混用。

`tools/check_calibration_cli.py` 的28张棋盘图是合成测试样本；`tools/check_profile_export.py` 中改变焦距的配置是重绑定测试数据，都不能作为上述真实相机采集材料。

## 上板演示与实测

最终合格候选下载后，再恢复“相机 → 板卡HDMI IN、板卡HDMI OUT → 采集卡 → OBS”。正常状态显示镜头校正结果，按住KEY1对照原图，KEY2对照最近邻取样；具体按键以该发布版说明为准。KEY0会复位，不用于图像对照。

可双击根目录 `打开角度控制面板.cmd`。先刷新并选择板卡CP2102串口，填写旋转角度、放大倍数，点击“应用到板卡”。“仅做离线检查”不打开COM口。收到新帧参数确认，只表示新帧已经锁定参数，显示仍需等待该帧完成和正常发布。小角度模式会进行适量等比裁剪以保持缓存效率，界面显示实际放大倍数。

先保持固定镜头和棋盘，对照原图与校正图的直线度，再发送0°、正/负12°等角度命令，观察连续画面和切换边界。自动追踪、IMU和额外四点透视当前暂缓，不将这些扩展写成已验收功能。

用实际显示帧ID或诊断发布计数计算30秒内的新校正帧数量，目标900张；同时检查异常计数、画面撕裂和原图/校正图切换。OBS设置30fps只说明录制格式，不能替代这个计数。

SFR/MTF50需要另拍适用的斜边测试图、记录线性或sRGB传递假设并指定有效ROI，参照 `SFR方法说明.md`。端到端延迟需要能共同观察输入事件与实际输出的物理测量；内部年龄计数或软件测试靶的刷新周期不能冒充精确的外部端到端延迟。
