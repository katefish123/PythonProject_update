# 本次完整候选接口核对

范围为本机 `b_lens_board_release2_20261023` 的精确源码，144 个顶层端口位的引脚、方向和冲突检查见 `interface_audit.json`。以下是代码和仿真核对，不代表已测量每条实体线路。

| 边界 | 数据和时钟 | 核对结果/约束 |
|---|---|---|
| 相机 → RX | PCLK、VS/HS/DE、RGB24；原生 1920×1080 | RGB 与三种同步共同下降沿捕获，再共同正沿重定时；既有 VS 恢复器随后处理。相位模型红绿测试和完整链路仿真已通过；RGB 实际色序未验收 |
| RX → DDR 写入 | 320 位包：类型2、银行1、代际32、字地址24、完整1、原因4、数据256；异步队列 | 每 8 像素打包为 256 位，每像素占 32 位、RGB24，填充字节保留；捕获写 ACK 后才允许发布源帧 |
| 源银行所有权 | 分配33、完成38、归还33位 | 两个源银行，不能在消费方仍持有时重写；RAW 显示也保留源租约。仿真含银行覆盖、代际和回压断言 |
| C → B 请求 | 四个像素地址各24位、目的 tag24、fx/fy 各8、generation32、inside/nearest；处理时钟约57.1MHz | valid/ready、额度限制；B 数学仍是原始镜头映射与插值。固定试标定不做纸框检测/自动求 H |
| DDR → B 返回 | 四邻域 RGB24×4、tag24、fx/fy、generation32、inside | 顺序与代际检查；过时代际可排空，不能写入当前结果。整幅定点期望图逐像素核对 |
| B → 结果写入 | write_addr24、RGB24、valid/ready | 完整结果 1920×1080；等待写桥排空后才发布，不能把算法最后一个输出当作内存已提交 |
| C → A DDR 引擎 | 28位字地址、256位数据、32位字节掩码、2048位8拍载荷 | 4字节地址单位；源/结果/BIST分区从实际实例参数核对，不相互覆盖 |
| 引擎 → DDR IP | AW/AR 28、ID4、LEN4，W/R 256，WSTRB32 | APB调试口固定停用；复位、PLL锁定、训练、自检及故障恢复保留。仿真内存模型不证明实体训练和DQS采样 |
| DDR → HDMI | 本地148.5MHz扫描，2200×1125总时序，1920×1080有效区 | 源/结果显示按完整帧提交换银行，输出RGB/VS/HS/DE共同寄存；60Hz扫描不等于60张新校正结果/秒 |
| 配置 I²C | 10MHz控制、400kHz总线、SDA开漏 | TX先配置；启动恢复性NACK与正式配置错误区分，未连接设备不得虚报ready；五项总线模型测试通过 |
| 模式按键 | KEY1/KEY2异步输入，同步至处理域 | KEY1按住请求RAW，松开请求校正；KEY2最近邻，默认双线性。模式在完整帧边界提交 |
| 实体 DDR | x32 DQ、4组DQS、4DM、15地址、3BA、125MHz差分参考 | FDC与已冻结板级基线相同，未改变电压、引脚或放宽时钟要求；仍需实板训练和长期稳定性验收 |

源帧每幅 8,294,400 字节。两个源银行和两个结果银行均按 32 位像素存储。B 的活动 `perspective_core.v`、`lens_distort_coord.v`、`bilinear_interp.v` 与原交付一致；旧冻结工程里已有的其他集成变体单独记录，不把所有同名文件都宣称为 B 最新原版。

固定镜头试验不使用角标 metadata，原本已设 RAW 式源准入；本次移除无用途的角标像素跨域/检测实例。管理器仍要求完整捕获的 writer_good 和最终写 ACK 才能 READY，不能把缺省 metadata 当作成功捕获。独立异常输入/所有权回归覆盖短行、缺行、多行、队列溢出、时钟暂停、过时代际归还和复位。

构建入口的147份设计文件、一份FDC、实际PDS引用、源码哈希均绑定；performance 重布线还绑定映射DB、放置DB、PCF及上游来源。最终资格必须覆盖慢/快角的 setup、hold、recovery、removal、pulse width，不能只看内部优化阶段的概览。

未完成的实体核对：相机实际颜色协商、HDR/色彩设置、线缆电气质量、真实DDR训练及恢复、RAW/校正清晰度、实际新结果帧率。诊断程序已见相机实景，但曾偏绿；该现象仍需下次接线排除。

独立物理输入计数也采用下降沿捕获、正沿重定时；复位仍是 clocks_ready，DDR 重试不抹除该计数。红例暴露旧边沿误计数，绿例通过停钟/恢复及复位测试。
