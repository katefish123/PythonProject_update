# OBS 中文诊断卡

不改 FPGA 码流；仅在 OBS 当前场景增加可隐藏、已锁定的“板上中文诊断”文字源。
状态文字使用透明背景和白字黑描边，不再用整块黑底遮住视频。源图自身保持不变。
正常演示或画质采样时，可通过后台隐藏此文字源。

`python panel.py --live` 每约 3 秒通过本机已认证 WebSocket 保存采集源原图，解码后更新中文文字。
密码由现有后台客户端从 OBS 本机配置读取，不打印、不复制到此目录。
重复启动前先核对已有进程，避免多个实例写同一文件。

界面区分当前故障、历史故障、画面有效标志、实际 RAW 模式和校正发布率。
无法完整解码时显示不可用；RXPROBE 识别为降采样预览，不假装完整校正。
图像年龄大不直接报溢出，历史故障不等于当前故障；欠载仍须查看 LED5。
发布率来自相邻后台采样的校正计数差和单调时钟，遇模式切换或计数回退分段。
不是精密光学帧率或端到端延迟测量，帧号推进不能证明实际场景正确。

`latest.json` 保留原始解码和中文解释，`samples.jsonl` 保存采样区间记录，`source_latest.png` 为无遮挡最新原图。
文字中带更新时间；若时间不再变化，不应继续将其当实时状态。
仅适用于本项目已核对的完整候选 HUD 位布局；其他码流须先核对字段。

验收：`python -m unittest test_status.py`，并通过 OBS 后台截图确认实际文字可见。
当前硬件未连接时只验证 UI 与解释规则；真实板上 HUD 联动待明天验收。
