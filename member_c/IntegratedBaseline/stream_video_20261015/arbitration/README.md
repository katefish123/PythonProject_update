# Outer DDR arbitration

Display keeps first priority. Capture and correction alternate when both request the next available transaction. The accepted owner's response remains qualified until retirement. Native block command flags follow the actual accepted correction grant, including when capture is also waiting.

The regression checks24 balanced accepts,4 display-priority accepts and28 retained response owners. The original capture-priority arbiter fails the starvation check (0 correction accepts,16 capture accepts). A higher correction quota was tried in separate output directories and rejected because it caused a display underrun in the reduced pressure test; that policy is not in this module.

The generated v4d candidate passes native12-image and reduced6-image pressure tests with exact RGB, generation and bank ownership; full-HD publication still averages33.456ms. This module is not hardware accepted.
