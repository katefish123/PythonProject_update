# 黑标原图的离线 B RTL 对照

2026-10-17 从硬件聊天导入既有实验，未重复运行仿真、未改板子及V5C实现输入。材料见 [证据包](offline_B_reference.zip) 和 [独立核验记录](verification.json)。

输入为已有 `review/materials/original_black_chart.jpg`，1586×992，SHA256 `9efd4b99fd10e32b899097ef52cdc53078be69c852d05c00e53c802f10c9caca`。电脑连通块定位、取整后四角TL/TR/BR/BL为(489,104)/(1331,197)/(1405,909)/(148,875)。直接输入冻结B原始求解器、坐标映射和双线性插值，采用现有765×1080输出约定。

原始日志报告 PASS OFFLINE_B_RTL，ModelSim耗时9秒、Errors 0、Warnings 0。此次导入核验：7个B源文件的SHA与V5C精确冻结输入一致；读取既有实际RTL输出hex的826200像素，与结果PNG及定点参考PNG逐像素一致，差异0；原JPG及结果PNG校验一致。证据包保存结果图、对照图、实际输出hex、日志、bench、脚本、H及B源快照。prepare_demo.py保留原实验绝对路径，搬移后须调整输入/依赖路径，source.hex可由原JPG重新生成。

可见外框已拉正，内部网格仍有残余偏斜。本实验支持“正确四角条件下，这组B核心RTL能产生参考一致的结果”。输入不是原始1920×1080相机帧，输出比例也未通过纸张物理尺寸验证，不能据此认定镜头畸变已消除。

本实验绕过板端检测，以理想图像数组供数，不含真实DDR或HDMI。V5C默认检测红/绿/黄/蓝角标，该黑标实验不验证V5C自动检测。下一步实板对照应保存同一帧的原始图、四角、H、源/结果bank及真正显示帧号，先核对检测配置与帧归属，再判断数据链路；现有证据不足以单独判定板上故障根因。

V5C sbit、smsk、PDS时序资格和硬件未验收状态保持原记录。
