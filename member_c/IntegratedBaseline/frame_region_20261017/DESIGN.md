# Same-size local frame routing and exact marker-mask cleanup

Implements the explicit user display contract, independently of V5C and existing numeric/DDR modules. No board programming. Source dimensions are retained: every source canvas pixel produces one routing result at the same x/y. Routing is RAW outside the actual supplied convex paper/pad boundary, FILL in vacated interior areas and on explicitly marked old-marker pixels, WARP only inside a supplied aspect-preserving target rectangle contained in that boundary.

This stage takes a **supplied** true boundary and frame-specific exact marker mask. It does not detect a boundary or generate component labels, infer physical paper ratio, repair text, estimate calibration or issue DDR requests. A marker bounding box is not a pixel mask and must not be used to erase unrelated outside content. Existing image-specific grid/text fitting is not imported.

Configuration includes source dimensions/mode, clockwise TL/TR/BR/BL corners, target x/y/width/height, explicit rational target aspect, background RGB, marker enable, source frame/bank/version and synthetic provenance. The aspect is supplied and recorded; integer dimensions must agree within nearest-pixel rounding. Real physical aspect provenance remains a host/measurement requirement. Independent development currently accepts synthetic provenance only.

Geometry validation is sequential: complete bounds/metadata/aspect checks, four strict convex turns, then four rectangle corners against four edges. No pending bundle until validation completes. At frame boundary, commit only if both routing stages are empty and downstream has retired old requests. Otherwise defer to a later boundary. Runtime size/mode is rechecked at commit and per request. Seal/arrival on a boundary does not commit immediately. Source-frame/bank/version or enabled-mask association mismatch returns RAW with scene_valid=false; downstream must reject it as a corrected frame.

Datapath: two elastic stages, one accepted pixel/clock when downstream ready. Precomputed signed edge coefficients avoid division per pixel; all identity/color/local-coordinate/association metadata are captured with the transaction and stable under backpressure. Frame-start blocks input acceptance on that edge. Output route0 RAW,1 FILL,2 WARP; RGB is the unchanged source payload for RAW/WARP, background for FILL. WARP RGB is not a corrected result: its local coordinates must enter the validated mapping/sampling path.

source_marker_clean is a separate one-stage elastic four-neighbor prefilter. Exact per-neighbor marker flags replace only marked source pixels with background before the **single** B interpolation. Mask frame/version must match the sampling request; mismatch reports error and leaves all neighbors untouched. It does not mutate DDR source images. The final old-marker removal requirement needs both destination routing and source-neighbor cleanup; actual mask generation and integrated sampling remain unqualified.

Validation: exact outside identity on a complete1920x1080 synthetic scan, no cropping/resizing, route category counts, ideal1pixel/clock admission, random stalls/stable packets, bad geometry/aspect/dimensions, stale masks/source identities, deferred commit/downstream outstanding requests, runtime mode changes and reset. Physical image quality, real detection, complete warp throughput and final board timing remain separate acceptance gates.
