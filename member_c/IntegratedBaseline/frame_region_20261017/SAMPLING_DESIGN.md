# Single-sample executor integration plan

Continuation of the approved same-canvas/single-source-sample design. Preserve frozen V5C, original B and numerical baselines. Add a separate executor consuming frame_region descriptors. RAW/FILL bypass mapping and memory; WARP snapshots the entire Brown/H profile and metadata, uses the existing exact fast composed mapper, issues exactly one four-neighbor memory transaction, applies exact source masks, then invokes unchanged B bilinear_interp once. Q34.30 coordinates truncate to UQ0.8 fractions matching B; last-row/column neighbor clamps to the same edge.

Initially one descriptor outstanding: preserve order and all metadata through variable memory delays and output stalls. This is correctness integration, not full-HD real-time throughput. Input profile/frame/version/dimensions must match; out-of-domain coordinates fill background but are not arithmetic faults; invalid mapping or response/mask association failures set error and scene_valid=false. A frame publisher must collect all pixels and reject a frame containing any invalid scene/error before publishing CORRECTED. That publisher and physical DDR adapter remain separate.

Memory response must echo tag/frame/version/bank; exact mask frame/version travels with it. Request remains stable until accepted. After reset the external memory producer must cancel/drain old requests before releasing reset; this module cannot make an untagged physical memory controller reset-safe by itself. No timeout/abort/retry added in this isolated stage. Busy includes held output; it must feed downstream_idle of the region configuration owner.

Test first: original-B independent integer oracle, nonzero projective/Brown mapping fixture, RAW/FILL identity/bypass, fractional samples and edge clamp, all marker combinations, stale profile/response/mask rejection, request/output backpressure, coordinated reset and exact source snapshots. Then source-bound archive and review. No new board image or hardware claim.
