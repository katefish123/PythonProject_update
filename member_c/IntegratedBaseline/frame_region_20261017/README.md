# 同尺寸局部画面合成：独立开发模块

本阶段实现“框外保持、框内分流、旧标记按精确掩码清除”的基础模块，未接入整板，未产生新的烧录文件。V5C、原 B 算法、DDR/CDC/恢复和已有镜头数值模块均未修改。

- `frame_region.v`：校验给定凸四边形、目标矩形、比例及帧归属；输出 RAW、FILL 或 WARP 路由，保留输入画布坐标。配置只能在帧边界且本模块及下游请求全部退出后提交；失配输出 RAW 并置 scene_valid=0。
- `source_marker_clean.v`：在唯一一次插值前，仅替换四邻域中掩码明确标出的源像素。掩码失配保留原像素并报错，不直接改写 DDR。

**WARP 输出的 RGB 仍是辅助原始像素，不是校正结果。** 下游必须接组合坐标映射、源图采样，并拒绝把 scene_valid=0 的帧发布为 CORRECTED。这里不检测纸张、不生成标记掩码，也不推断真实物理比例。

## 验证

`verification.json` 绑定当前源文件 SHA 和 `evidence/synthetic_routing.zip`。四组通过：标记邻域清理、背压/帧切换控制、全高清画布、2/4096 尺寸几何边界。编译与仿真无警告、无错误。

1920×1080 合成画布逐点验证共 2,073,600 像素：RAW 725,208，FILL 829,992，WARP 518,400；框外未标记的 725,208 像素精确保留。持续 ready 条件下，首末接受跨度为 2,073,600 周期，即此路由模块每周期接受一个像素。**这不是完整校正链路的实际帧率或物理时序证明。**

三个故意破坏的对照均按预期失败：扩大邻域擦除、误填框外、下游忙时强制提交。归档保留这些失败日志用于证明测试能发现回归，不能把它们计入通过测试。

运行 `run_tests.ps1 -Suffix <新名称> -Bench tb_frame_region -Native` 可复验完整画布；默认测试邻域清理，`-Bench tb_region_geometry` 测尺寸边界。ModelSim 路径见脚本。`collect_evidence.py` 从指定输出目录重新核验、归档。

## 未完成

### 单次采样连接补充

新增 `region_sample.v` 独立执行器，接受上述路由描述符，实际连接既有 fast H＋Brown 映射、一次四邻域请求、精确标记清理及未改的原 B 插值。RAW/FILL 直接输出，WARP 现在可在这个执行器内产生采样 RGB；这不改变 `frame_region.v` 本身只输出路由和辅助 RGB 的接口。该执行器每次只处理一个像素，忙状态须参与配置提交的下游空闲判断。

`sampling_verification.json` 与 `evidence/synthetic_sampling.zip` 是这一补充的独立证据；原 `verification.json` 继续只描述前一阶段路由模块。1024 个既有独立组合映射向量（包含非零镜头系数与 projective H），972 个有效采样像素与原 B 定点参考一致；其余向量按数值拒绝/正常域外分别处理。另测全部 16 种邻域掩码、帧/bank/version/mask 失配、快照、背压、4096 末坐标钳位及协调复位。总计 1000 次已接受四邻域请求、992 次 B 插值，计数包括控制及错误用例；错误用例不会触发错误插值。三个故意错误对照均失败。

内存由行为响应器提供，尚未接物理 DDR；外部响应器必须在复位时取消/排空旧事务。这不是任意异步复位、超时或链路故障恢复资格。下游还须整帧汇总 scene_valid/error，含错帧禁止发布 CORRECTED。未完成的发布器和整板集成不能由单像素输出标志替代。

真实纸框与标记掩码生成、组合映射与 DDR 单次采样集成、整帧发布保护、完整链路吞吐、最终整板 PDS 时序、真实标定及独立图卡 MTF/SFR 验收仍缺。不能据此宣称模糊或慢刷新已经解决，也不能作为企业验收通过版本。
