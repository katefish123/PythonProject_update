# 尚未完成的工作

1. 本候选的真实板级验证：DDR 初始化、相机图像、持续帧更新、清晰度、断连恢复及长时间运行。仿真和最终 PDS 时序均不能替代此项。
2. 实时校正吞吐：输入和输出视频接口维持连续时序，并不代表每个输入帧都做完整校正。27MHz 下，完整源图扫描即使每周期一个像素也需 76.8ms；现有状态机和内存等待还会增加时间。
3. 下一轮优先消除独立源图扫描：研究在采集阶段并行累计角标检测，并将检测结果绑定到源图缓冲代次。这属于 C 调度改动，但必须验证像素坐标、帧边界、异常帧和跨时钟传递，不能只删去扫描步骤。
4. 插值和结果写入流水线：保持 B 的输入输出数值不变，通过 C 队列解耦返回像素、插值结果和 DDR 写入。应先验证队列容量、最后一个像素排空、错误重置及标签顺序，再判断收益。

以上项目没有因为此次缓存优化而自动完成。后续若要提高处理时钟，应重新检查时钟约束、跨域、超时和最终布局布线时序。
