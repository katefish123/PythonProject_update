## 定位到的性能现象

处理域忙碌28,179,966周期，其中取样请求阻塞15,442,288周期，约54.8%；写回阻塞744周期。UI缓存填充43,390,964周期，其中缓存读命令等待授权33,829,202周期，约78.0%。这些计数可能重叠，不能相加作为独立耗时百分比；等待授权也不能全部归因于显示优先级。

## 使用

```powershell
python -m unittest test_video_metrics test_board_geometry -v
python video_metrics.py --input simulation.log --format modelsim --time-unit ps --output fresh_metrics.json
python video_metrics.py --input display_samples.csv --format display-csv --output fresh_display_metrics.json
python board_geometry.py --raw raw.png --corrected corrected.png --output fresh_geometry.json
```

CSV列为 `time_s,frame_id,mode`，只分析连续、有效、无复位的CORRECTED段。时间须来自同一记录时基；模式切换、复位和无效段分开处理。不能以源帧号跨度当作处理图数。样本取自录制视频时应记录真实时间戳、解码失败区间和采样间隔，容器宣称60fps本身不证明60张不同相机图像。
