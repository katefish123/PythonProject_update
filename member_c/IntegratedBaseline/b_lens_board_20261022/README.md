1. 原 B 包 11 项原生 ModelSim 测试通过，保留原包结果不覆盖。
2. `prepare_test.py` 使用 B 精确定点映射生成两幅不同原生 RGB 图和一次插值期望；未接入候选的旧分支先因 `B_LENS_TRIAL_NOT_CONNECTED` 失败。
3. `prepare_board.py` 从精确 V5C 输入生成独立候选，只更改/增加七份设计文件；无标记镜头实验绕过角标判定，但仍等待整帧源写 ACK。原有请求额度、代际、DDR/CDC、结果提交和恢复保留。

5. `run_test.ps1 -Suffix <新名> -Sources <候选sources>`：实际应用层 DDR、仿真原生内存端、HDMI 共核验 14,515,200 像素、两幅不同校正帧；加 `-Raw` 核验 4,147,200 像素、两幅 RAW。源银行/结果银行覆盖与显示代际断言全部保留，零错误警告。仿真内存延迟不等于真实 PHY。
6. 完整 PDS 构建后由 `qualify.py` 检查精确源 SHA、最终全部慢/快角五类时序、码流及 mask，才生成 release/qualification.json 和临时 CRAM 编程入口。此步骤未通过时不允许烧录。
