# 完整 1920×1080 源图，竖向文档校正

本目录接续 A 的 `6b0b2e2` 高清候选版，落实用户确认的“保留全高清原图、纸张不横向拉伸”。旧候选版的 960×540 源采样不再用于本目录生产顶层。

数据路径：相机 1920×1080 → 每个有效像素写入 DDR → 在完整源图上检测角标与读取四邻域 → 640×904 竖向结果 → 居中放入 1920×1080、60 Hz 输出，左右留空。结果窗口沿用项目既定文档比例；没有加入任意纸型的自动长宽比识别。

## 修改范围

只覆盖 A 的两个生产 RTL：

- `video_correct_ddr_top.v`：完整源采样、生产角标阈值、结果及自检地址；DDR 预取引擎使用同一结果地址。
- `video_correct_ddr_core.v`：把结果地址传到写入器和显示读取器，把角标阈值传到 B 调度模块，把自检地址传到 DDR 自检。

A 的 DDR IP、引脚约束、采集模块、异步 FIFO、仲裁、字引擎、像素缓存和 B 算法均继续复用。旧版本在 `../a_sync_20261013/` 保留。

以下为 **32 位字地址**，每个 RGB888 像素以 `0x00RRGGBB` 占一字；换算字节地址须乘 4：

| 区域 | 起始字地址 | 占用字数 | 起始字节地址 |
| --- | --- | --- | --- |
| 完整源图 | `0x0000000` | 2,073,600 | `0x0000000` |
| 结果银行 0 | `0x0200000` | 578,560 | `0x0800000` |
| 结果银行 1 | `0x0400000` | 578,560 | `0x1000000` |
| 自检区 | `0x0600000` | 2,048 | `0x1800000` |

角标面积下限/上限由 16/4096 调整为 64/16384，最大跨度由 128 调整为 256，对应源采样密度提高四倍。同一实际标记不应仅因恢复原分辨率而被旧面积阈值拒绝。

## 可复现检查与构建

从仓库根目录运行。需要 Python（NumPy、Pillow）、ModelSim、PDS；先确保 A 的固定提交已通过 `git fetch origin main-A` 获取。

```powershell
$full='member_c/IntegratedBaseline/fullhd_source_20261013'
$shared='member_c/IntegratedBaseline/a_sync_20261013'
$out='D:/FPGA/output/c_fullhd_source_new'
python "$full/prepare.py" --output $out
python "$full/check_configuration.py" --output $out
& "$shared/run_hires_reproduction.ps1" -OutputRoot $out -RequiredChecks 16
& "$shared/build_hires_reproduction.ps1" -OutputRoot $out -RequiredChecks 16 -PdsExe 'D:/softwares/PDS/PDS_2022.2-SP6.4/bin/pds_shell.exe'
python "$shared/package_hires_reproduction.py" --root $out --build "$out/build_实际生成时间" --output 'D:/FPGA/output/fullhd_package_new' --expected-tests 16
```

复现工具保持 A 的源码闭包，应用两个覆盖文件后记录原始及本地哈希。仿真前后、构建前后、打包时均校验输入。原生全高清测试图包含逐像素变化的细节和四色标记，黄金值来自固定版本 B Python 定点模型，不由 RTL 自己生成。

除原 12 项回归外，增加：

1. **全源图采集与显示争用**：148.5 MHz RX、125 MHz UI，一完整源帧 259,200 个存储拍逐像素检查，同时核对两个显示帧。模型加入周期性写等待及读延迟/刷新等待；这不是真实 DDR 带宽测量。
2. **采集后全帧校正**：通过真实采集、FIFO、写入器填充源内存，完整提交后启动像素缓存与 B 校正，逐一核对 578,560 个结果像素。
3. **新地址分区整核测试**：在小尺寸模型中验证两个结果银行、自检、发布和复位恢复，使用生产的新基址。
4. **异常采集回归**：短行、短帧、溢出和复位恢复。

组合验证分为数据正确性、实际像素速率压力、帧会话恢复三个层次；没有把这些模型宣称为真实相机到屏幕的完整现场验收。
