# 成员 C：视频与硬件

当前版本：V2（成员 C 的第二次正式提交）

工程入口：`VideoTimingSim/`

本版本包含：

- 参数化 1920×1080 视频时序控制器（VTC）
- 竖彩条、纯色、四象限测试图案发生器（TPG）
- 缩小参数教学仿真、TPG 独立检查和完整 1080p 整帧检查
- ModelSim 运行脚本、模块说明与验证日志

验证结果：

- TPG 检查：0 Errors，0 Warnings
- 1080p 整帧检查：2,475,000 个像素位置、1,125 行，0 Errors，0 Warnings

当前边界：尚未加入盘古 676 的 PLL、PDS 管脚约束、HDMI 芯片初始化、HDMI 输入输出和 DDR3 缓存；这些内容需要开发板和官方例程参与联调。

## 版本记录

- V1：首次保存已验证的 VTC、TPG 和 ModelSim 仿真基线；原分支与标签继续保留。
- V2：第二次正式提交，将成员 C 的成果按团队仓库目录和命名规则归档。VTC、TPG 的 HDL 功能与 V1 相同，本次没有虚构新的功能改动。

以后成员 C 每次正式上传都按 `V1 → V2 → V3` 递增，并保留此前的分支和标签，方便随时查看和比较历史版本。
