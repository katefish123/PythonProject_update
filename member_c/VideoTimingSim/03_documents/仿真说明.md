# ModelSim 仿真说明

## 软件分工

- VS Code：编写和阅读 Verilog 代码。
- ModelSim：编译代码、运行 Testbench、观察波形。

两款软件读取同一份文件，不需要复制或迁移代码。VS Code 保存后，回到 ModelSim 重新编译即可。

## 为什么有四份 Testbench

| 文件 | 用途 |
| --- | --- |
| `tb_video_timing.v` | 把时序缩成 14x7，方便学习和肉眼观察波形 |
| `tb_video_timing_1080p.v` | 使用正式默认参数，自动检查完整 1080p 一帧 |
| `tb_tpg_patterns.v` | 不依赖 VTC，直接检查 TPG 的竖彩条、纯色和四象限 |
| `tb_video_top.v` | 检查正式可综合顶层的参数传递、模块连接和完整一帧输出 |

缩小版用于“看懂”，正式版用于“证明真实参数没有写错”。

## TPG 独立检查

在工程根目录运行：

```text
vsim -c -do run_tpg_check.do
```

成功标志：

```text
TEST_PASS_TPG: all pattern modes are correct
```

完整记录保存在 `04_results/tpg_check.log`。

## 顶层集成检查

在工程根目录运行：

```text
vsim -c -do run_top_check.do
```

该检查使用 14x7 缩小参数，检查 VTC 到 TPG 的内部连接、四种图案选择、同步、`de`、消隐黑色和完整一帧输出。成功标志：

```text
TEST_PASS_TOP: VTC and TPG top-level integration is correct
checked pixels: 98
```

完整记录保存在 `04_results/top_check.log`。

## 教学波形

在 ModelSim 中执行根目录的 `run_wave.do`。脚本会依次编译 VTC、TPG 和教学 Testbench，加入 `clk`、`rst_n`、`h_cnt`、`v_cnt`、`hsync`、`vsync`、`de`、`rgb` 并运行到测试结束。

成功标志：

```text
TEST_PASS: complete video timing and RGB output are correct
```

## 正式 1080p 检查

在工程根目录运行：

```text
vsim -c -do run_1080p_check.do
```

该检查把 VTC 与 TPG 连接起来，逐像素核对一整帧，包括计数器循环、同步宽度、有效区边界和四段彩条。成功标志：

```text
TEST_PASS_1080P
checked pixels: 2475000
checked lines : 1125
```

完整记录保存在 `04_results/1080p_check.log`。
